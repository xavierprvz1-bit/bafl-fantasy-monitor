# BAFL Fantasy Monitor

BAFL Fantasy Monitor is a personal, non-commercial fantasy football analytics project for a single private Yahoo Fantasy Football league.

## Purpose

The application uses authorized, read-only Yahoo Fantasy Sports data to assist with personal fantasy football analysis.

Data may include:

- League settings
- Team rosters
- Matchups
- Standings
- League transactions
- Waiver and free-agent information
- Player information

The data is used to support personal roster, lineup, waiver, trade, and matchup analysis.

## Access

This application is intended for one user and one private fantasy football league.

It does not make automated roster transactions, redistribute or resell Yahoo Fantasy Sports data, or provide a commercial fantasy service.
